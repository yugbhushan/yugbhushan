# Working with this portfolio

Use Python 3.12 and the pinned root requirements. Run `python -m unittest discover -s tests -v` and `python run_all.py` before submitting code changes.

Keep original project claims separate from reconstruction results. For each new result, record the input source, units, split or boundary conditions, parameters, versions and run command. Label synthetic fixtures and illustrative simulations explicitly.

Do not commit private datasets, API keys, credentials or unpublished collaborator material. Preserve the authorship of the packed-bed term paper. Discuss substantive model changes in an issue or pull request, including their effect on the outputs.

The source files under `papers/` preserve supplied report implementations. Make a documented new version rather than silently changing a manuscript's experiment.
